KNK Kafé app – setup (GitHub)

1. Apps Script: naya Code.gs paste > Deploy > Manage deployments > Edit > New version
   Who has access: Anyone. Web app URL copy karo.
2. GitHub > New repository (Public), naam jaise knk-kafe-dalibagh.
3. "uploading an existing file" > is folder ke ANDAR ki saari files/folders drag karo
   (index.html, config.js, common.js, staff, counter, pantry). Commit.
4. Add file > Create new file > naam: .github/workflows/deploy.yml
   deploy.yml ka content paste karo > Commit.
5. Settings > Pages > Source: GitHub Actions.
6. Settings > Secrets and variables > Actions > Variables > New variable
   Name: KNK_API_URL   Value: Apps Script web app URL
7. Actions tab > "Deploy KNK Kafé app" > Run workflow (ya koi bhi commit karo).
8. App links:
   https://<github-username>.github.io/knk-kafe-dalibagh/staff/
   https://<github-username>.github.io/knk-kafe-dalibagh/counter/
   https://<github-username>.github.io/knk-kafe-dalibagh/pantry/
